# ☕ UCF Paradise Coffee Shop
### COP 4331: Processes for Object-Oriented Software Development (Spring 2026)
**Midterm Project: Full-Stack CRUD Contact Manager**

Welcome to **UCF Paradise Coffee Shop**, a coffee-shop themed contact management system where organization meets relaxation. Designed for the Spring 2026 COP 4331 Processes of Object-Oriented Software Development small Project, this application transforms the standard "Contact Manager" into a cozy digital café experience.

---

## 🌺 The Experience
Upon entering, users are greeted by our **lovely barista**, designed and rendered using **Gemini Nano Banana Pro**. The interface provides a warm, inviting atmosphere to manage your professional and personal connections.

### Key Features:
* **Secure Entrance:** Full Login and Registration system to protect user data.
* **Contact Hub:** A seamless dashboard to view all saved contacts.
* **Dynamic Search:** Real-time filtering to find contacts instantly.
* **Full CRUD Suite:** * **Create:** Add new contacts with detailed info.
    * **Read:** Clean, organized display of your "Coffee Club" list.
    * **Update:** Edit existing contact details through a sleek modal.
    * **Delete:** Remove contacts with a confirmation prompt.

---

## 🛠️ Technical Architecture (LAMP Stack)
The project follows a classic **LAMP** architecture, optimized for performance on Linux-based Apache servers.

| Component | Technology |
| :--- | :--- |
| **Operating System** | Linux (Ubuntu/Debian) |
| **Web Server** | Apache |
| **Database** | MySQL |
| **Backend** | PHP (API Endpoints) and JavaScript (logic) |
| **Frontend** | HTML5, CSS3, JavaScript |
| **AI Visuals** | Gemini Nano Banana Pro |

### Implementation Details:
* **API Endpoints:** PHP scripts handle the server-side logic, processing JSON requests from the frontend.
* **Frontend Logic:** Vanilla JavaScript manages the state, DOM manipulation, and `fetch` calls to the PHP backend.
* **Database Schema:** A relational MySQL structure mapping Users to their specific Contact lists. Registered Users have a one-to-many relation with candidates.
